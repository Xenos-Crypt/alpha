# Another World

A browser town simulation with a first-person body, phone selfie, powers and autonomous residents. Bodycam is the environmental realism reference; this is a playable visual foundation, not equivalent photorealism.

## Play

Run `npm install`, then `npm start`. Open **http://localhost:8080** in a desktop browser with WebGL 2 enabled. Dependencies and downloaded assets are local; playing does not require third-party services. Opening index.html directly is no longer supported because the game uses JavaScript modules and loads assets.

Click **Enter the world** to capture the mouse. **WASD** moves, **Shift** runs, **mouse** looks, **E** talks to a nearby resident, **Q** releases an impulse, **P** opens the selfie phone, and **H** hides the interface. **Escape** releases the mouse so you can click Pause or other controls. Click the scene to resume looking around.

The Corner Café has a walkable entrance between its shop windows. Residents plan routes around buildings and vehicles. Hunger, sociability, fear and trust influence their choices and conversations. An impulse frightens nearby residents and damages relationships. Empathy and healing residents calm others nearby. These are local decision rules; there is no LLM backend, online multiplayer or persistent save yet.

## Graphics

Three.js provides physically based materials, HDR environment lighting, sunlight and shadow maps. The scene includes photographed surface maps, detailed procedural façades, roof geometry, cars, street furniture, instanced leaves and a café interior. The phone renders the same 3D player model through a second camera. The player's head is hidden from the main view.

Residents and the player now use textured, skeletally animated human GLBs, with Idle, Walk and Run states. Residents share two base characters with subtle clothing tints; a diverse civilian cast remains future work. Architecture is still procedural. Detailed scanned scenery, reflections in mirrors and more extensive interiors remain future work. Bodycam-level fidelity has not been achieved.

## Assets and checks

Downloaded maps and HDR sky are from [Poly Haven](https://polyhaven.com/license), licensed CC0. Exact sources and files are listed in [assets/manifest.json](assets/manifest.json); these surface and sky assets total about 14 MB. Human models add about 5 MB; see [character credits](assets/characters/CREDITS.md) for source and usage terms. Town geometry is generated by this project. Three.js is MIT licensed; its license is installed with the package.

With the server running, `npm test` checks real WebGL rendering, asset requests, animated residents, powers, conversation trust, selfie, pause, keyboard movement, collisions and resizing in headless Chrome. Set `CHROME_PATH` if Chrome is installed elsewhere. Tests save screenshots in `test-results/`; headless browser performance does not establish frame rates on players' hardware.

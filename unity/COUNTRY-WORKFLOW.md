# Country and continent workflow

Hidrok is a fictional hidden Antarctic enclave containing Ashford, Riverside, Ashford Capital, Northhaven and Poison Land. Its interior geography comes from the existing game. `Assets/Resources/World/atlas.json` records country identity separately from its cities. `WorldGeography` restores the regional land, ocean, six islands, bridges and destinations. Regional grids use the wider 64 m street spacing, so their footprints expand relative to the web version. `HidrokClimate` encloses the interior in a 1,700 m radius shielding hemisphere, maintains the fictional 22 C interior climate, hides the interior from exterior views, applies outdoor cold exposure, and surrounds the enclave with Antarctic ice and research saucers. This is fictional Antarctic scenery, not a reconstruction of the whole continent.

Additional real-world countries must be imported from geographic data, rather than generated by copying Country 1. Keep coastline polygons, land-use polygons, roads, building footprints and elevations in separately versioned tiles. A country needs a geographic origin and projection, source attribution and a tile manifest before being added as a playable country. Downloading data alone does not make a completed country.

Antarctica is a continent region, not a country. Its import must preserve its polar coastline, islands, terrain and ice elevations. Use a south-polar projection for geographic data there; the normal country importer must reject polar latitudes. Research stations and inland features need sourced locations. Do not generate fictional cities across Antarctica or show an empty continent as playable.

Large regions need loading by tile near the player, with bounded memory and a distant terrain representation. Do not eagerly instantiate every building in a real country. Future country travel should load that country's world separately, preserving the player/account state. The current country atlas is metadata; cross-country travel, streamed real-world tiles and geographic reconstruction of the full Antarctic continent are not implemented yet.

Release the updated first country only after Unity runtime and browser checks cover every city, island landing point, ocean boundary, bridge route, ferry boarding and vehicle blocking. Account/chat/combat/quest/save migration is separate from geography; replacing the original website requires verifying those features rather than dropping them.
